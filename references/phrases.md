# 削除すべきフレーズ

## 前置きの咳払い（Throat-Clearing Openers）

文頭や段落冒頭の announcement 句。本文から直接始める。

- 「実は」
- 「ところで」
- 「さて」
- 「結論から言うと」
- 「核心はこうだ」
- 「以下に〜について」
- 「ここで重要なのは」
- 「興味深いことに」
- 「ぜひ言っておきたいのは」
- 「あらかじめ言っておくと」
- 「先に断っておくと」
- 「ちなみに」
- 「なお、」（文頭の補足）

→ すべて削除し、内容を直接書く。

## 強調の松葉杖（Emphasis Crutches）

意味を加えていない強調句。

- 「重要なのは」
- 「特筆すべきは」
- 「強調すると」
- 「だからこそ」
- 「ここがポイント」
- 「ここが面白い」
- 「ここで注目したいのは」
- 「忘れてはならないのは」
- 「念のため言うと」
- 「言わずもがな」

→ 削除する。本当に重要なら文構造で示す。

## 副詞（Adverbs）

意味を加えていない副詞。原則全削除。

### 強調系
- 「とても」
- 「まさに」
- 「本当に」
- 「真に」
- 「決定的に」
- 「深く」
- 「強く」

### 限定系
- 「単に」
- 「ただ」
- 「ただ単に」
- 「ひたすら」

### 評価系
- 「実は」
- 「実際」
- 「実質的に」
- 「本質的に」
- 「本来」
- 「結局」
- 「最終的に」
- 「素直に」
- 「正直」
- 「単純に」
- 「必然的に」
- 「自然と」

### 関心引き系
- 「興味深いことに」
- 「重要なことに」
- 「驚くべきことに」
- 「面白いことに」
- 「予想通り」

→ 副詞のほとんどは削除可能。残すのは意味を変える限定的な場合のみ。

## ビジネス・ジャーゴン（Business Jargon）

カタカナ濫用と抽象表現の置換候補。

| 避ける | 使う |
|:---|:---|
| ナビゲートする | 対処する、進める |
| アンパックする | 整理する、解説する |
| リーンする / lean into | 受け入れる、取り組む |
| ランドスケープ | 状況、領域 |
| ゲームチェンジャー | 重要な転換点、決定的変化 |
| ダブルダウン | 強化する、増やす |
| ディープダイブ | 深掘り、詳細分析 |
| ステップバック | 立ち戻る、再考する |
| ムービングフォワード | 今後、次に |
| サークルバック | 戻る、再訪する |
| オンザセイムページ | 一致している、認識を合わせる |
| エンゲージメント | 参加、関与、反応 |
| インサイト | 知見、気づき |
| コミットメント | 約束、責任、関与 |
| アラインメント | 一致、整合 |
| シナジー | 相乗効果 |
| パラダイムシフト | 大きな転換 |

→ 日本語訳を併記し、初出のみカタカナを使う。

## メタコメント（Meta-Commentary）

記事自身の構造に言及する自己参照句。本文を流れさせる。

- 「ここから〜していきたい」
- 「この節では」
- 「以下で見ていく」
- 「あらかじめ言っておくと」
- 「メッセージは短くまとまる」
- 「結論は単純だ」
- 「言いたいことは 1 つ」
- 「順を追って説明する」
- 「ここまでをまとめると」
- 「以上を踏まえて」

→ 削除する。記事は announce せずに move する。

## 怠惰な極論（Lazy Extremes）

具体性のない sweeping claims。

- 「常に」
- 「いつも」
- 「全て」「すべて」
- 「決して」
- 「すべての」
- 「皆」「皆が」「皆さんが」
- 「誰もが」
- 「絶対に」
- 「100%」（強調文脈）
- 「いかなる〜も」

→ 具体的な範囲・条件に置換する。「常に〜」→「7 割の場合〜」。

## 曖昧な断定（Vague Declaratives）

具体を伴わない抽象だけの宣言。

- 「本質的に重要だ」
- 「構造的な問題だ」
- 「示唆は深い」
- 「実装上の課題」
- 「根本的な変革」
- 「重要な転換点」
- 「大きな意味を持つ」
- 「深い意味がある」
- 「考えさせられる」
- 「示唆に富む」

→ 具体的な内容を述べるか、その文を削除する。

## 締めの定型句（Closing Cliches）

記事末尾の使い回し句。

- 「参考になれば幸いです」
- 「ぜひ試してみてください」
- 「まずは小さく始めましょう」
- 「ご意見お待ちしています」
- 「皆さんはどう思いますか」
- 「ぜひ気軽にお試しを」
- 「いかがでしたでしょうか」
- 「お役に立てれば嬉しいです」

→ 削除する。記事は内容で終わる。

## 安直なまとめ表現（Cliched Closures）

章末・記事末で読者に評価を押し付ける句。

### 陳腐な比喩
- 「両輪」「両翼」「2 本の柱」「2 本立て」「2 枚の翼」「車の両輪」
- 「車輪の再発明」「氷山の一角」「ブラックボックス」（記事末）

### 偶然の必然化
- 「揃った」「出揃った」「同じ日に揃った」「期せずして」「奇しくも」
- 「歴史が動いた」「点と点が線になる」

### 過剰意味付け
- 「象徴する」「物語る」「示唆する」「映し出す」「浮き彫りにする」「炙り出す」

### メタコメント型まとめ
- 「メッセージは短くまとまる」
- 「結論は単純だ」
- 「言いたいことは 1 つ」

→ 数字を最後の一語にする / 断定で終わる / 観察事実だけ並べる。

**許容**（誤検出回避）:
- 「受動的締め（〜が問われている / 試されている / 求められている）」
- 「時代論評（AI 時代の〜 / 〜時代の〜）」

これらは記事の主題を読者に投げ返す機能として有効。

## 演出的フラグメント（Performative Emphasis）

不自然な親密さの演出。

- 「creeps in」相当の「忍び寄る」
- 「I promise」相当の「断言する」「保証する」
- 「they exist, I promise」相当の「本当に存在する」

→ 演出を削除し、事実だけ書く。

## 「示すのではなく告げる」（Telling Instead of Showing）

困難や重要性を announce するだけで demonstrate していない句。

- 「これは本当に難しい」
- 「これがリーダーシップの本当の姿だ」
- 「これこそが X の本当の姿だ」
- 「actually matters / 真に重要」

→ 具体的に示す。announce しない。
